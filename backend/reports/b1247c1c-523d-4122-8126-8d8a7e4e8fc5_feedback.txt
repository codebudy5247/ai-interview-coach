🏆 IDEAL ANSWER
  "A Python decorator is a higher-order function that takes another function as an argument, adds some functionality, and returns a new function. Syntactically, we apply them using the '@' symbol above a function definition to 'wrap' it without changing its source code. For example, an authentication decorator would check a user's permissions in an inner wrapper function; if authorized, it calls the original function using *args and **kwargs, otherwise it raises an error. This allows for clean, reusable code across different parts of an application."
