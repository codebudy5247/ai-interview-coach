🏆 IDEAL ANSWER
  "A closure is a feature where an inner function has access to the outer function's variables even after the outer function has finished executing. This happens because JavaScript functions maintain a reference to their lexical environment at the time of creation. In practice, closures are used for data privacy—to create private variables that can't be accessed from the outside—and for functional programming patterns like currying or partial application. For example, a function that returns another function to increment a hidden counter is a classic implementation of a closure."
